# DOMUS-WEB

Portal corporativo interno de Domus Monge.

## Estructura

- `dist/index.html`: aplicación web estática.
- `dist/styles.css`: diseño responsive y accesible.
- `dist/app.js`: navegación, búsqueda y tareas locales.
- `.openai/hosting.json`: configuración de publicación privada en Sites.

## Uso local

Abre `dist/index.html` en un navegador o sirve la carpeta `dist` con cualquier servidor estático.

La lista de tareas se guarda únicamente en el navegador del usuario mediante `localStorage`.
