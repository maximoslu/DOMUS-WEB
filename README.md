# DOMUS-WEB

Landing corporativa de Domus Monge, empresa dedicada a la inversión y gestión inmobiliaria de naves, viviendas y locales.

## Estructura

- `dist/index.html`: aplicación web estática.
- `dist/styles.css`: diseño responsive y accesible.
- `dist/app.js`: navegación móvil y animaciones de entrada.
- `.openai/hosting.json`: configuración de publicación en Sites.

## Uso local

Abre `dist/index.html` en un navegador o sirve la carpeta `dist` con cualquier servidor estático.

La página es estática y no recoge ni almacena datos personales.
